## 已经更新的细节
1. **对齐了 DAG 学习的核心逻辑（至关重要）**
   - 和 Eco 脚本一样，现在在进行 DAG 贝叶斯网络学习时，显式地将 `"presence"` (物种分布状态) 加入到了网络拓扑结构的学习中。
   - 随后在提取环境变量的纯网络特征时（`strong_env_edges`），又巧妙地将连接到 `presence` 的边剔除，从而计算出完全针对环境驱动机制、且具有“物种特异性”的 DAG 密度 (dag_density)。
2. **对齐了 CI-MLP 的底层训练数据输出 (Learning Curves)**
   - 在 `run_nn` 的训练循环里，补充了对底层训练、验证损失函数历史记录集的抓取。
   - 结果会自动持久化保存到 `all_learning_curves_plant_v3.csv` 文件中，这使得后续做 Plant 版本的 figS3 训练曲线验证图成为可能。
3. **对齐了真实的 CATE 因果森林空间分布制图 (Step 7)**
   - 完整引入了 `grf::causal_forest` 处理板块。
   - 脚本会在最后自动选取最重要的 **Top 3 显著因果变量**，运行因果森林估算连续条件平均处理效应 (CATE)。
   - **注意：** 我专门兼顾到了 Plant 数据集特殊的表头结构，把 CATE 空间图的经纬度正确映射成了 `Longitude` 和 `Latitude`（而不是 Eco 里的 `lon` `lat`）。
   - 输出结果将整合存入 `all_spatial_cate_plant_v3.csv`。
4. **对齐了断点续传与全局输出文件命名机制**
   - 输出的统计表统一了命名后缀，例如 `all_results_plant_v3.csv`, `all_ate_results_plant_v3.csv` 等，并完美适配了断点续传机制。如果你的训练中途断掉，它完全会从尚未处理的物种自动恢复。

## 四个小节的排布
### 3.1 工具包标准输出：单物种因果流程展示

- 目的：说明 CAST 工具包一次运行后的标准产出是什么，便于读者/用户理解「我跑 CAST 会得到哪些图/表」。
- 内容：以 几个代表物种为例，展示：
  - 共识 DAG（节点因果角色着色）；
  - ATE 森林图（含 95% CI）；
  - CAST 筛选得分分解（DAG + ATE + RF 三成分）及保留/剔除边界。
- 对应图表：图2（`fig2_single_species_showcase.R`）。

------

### 3.2 物种间因果结构与效应的异质性

- 目的：说明工具包在批量物种上的产出——因果结构、效应方向、因果角色和筛选优先级均因物种而异；这是「相关性 + 变量重要性」给不出的信息。
- 内容：
  - 少量通用边 vs 大量物种特有边（DAG 边频谱）；
  - 同一变量在不同物种中 ATE 正/负不同（ATE 热力图）；
  - 同一变量在不同物种中扮演根/中介/末端（因果角色热力图）；
  - 不同物种对变量的筛选得分差异（筛选得分热力图）。
- 对应图表：图3（`fig3_species_specific_causal_structure.R` 的 a–d）。

------

### 3.3 CAST 与基线、传统模型的预测性能对比

- 目的：证明工具包在提供因果输出的同时，预测性能不逊于甚至优于常规 SDM，便于用户放心采用。
- 内容：
  - 全物种、多模型（CAST / MLP_ATE / MLP / RF / BRT / MaxEnt）的 AUC（及可选 TSS）；
  - 模型排名分布；
  - 与 CAST 的配对比较（如 Wilcoxon）及汇总表。
- 对应图表：图4（`fig4_performance_robustness.R`）+ 表2（`table2_performance_summary.py`）。

------

### 3.4 因果方向性与空间异质性：工具包独有的可解释性

- 目的：集中展示 CAST 相对传统 SDM 的两类独有产出——因果方向（正/负）和空间异质性（CATE 图），对应工具包的两类「出口」。
- 内容：
  - 因果方向性：
    - 预测重要性（如 RF）与因果效应（ATE）排名不一致；
    - 同一变量在不同物种中 ATE 可正可负（方向异质性）；
    - 强调「工具包给出的是有符号的因果效应，而非仅标量重要性」。
  - 空间 CATE：
    - 若干实例物种的显著因果驱动变量的 CATE 空间图；
    - 简要说明：同一驱动因子在不同空间上效应强弱/方向不同，可用于保护优先区或迁移性诊断。
- 对应图表：图5（`fig5_causal_directionality.R`）+ 图6（`fig6_spatial_cate_maps.py` 的若干物种×变量 CATE 图）。
