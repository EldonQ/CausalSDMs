# 3.2 物种间因果结构与效应的异质性 — 图3 客观结果分析

本文档对图3 四个子图进行严谨解读，明确每图所示内容、定义与局限，并给出结果部分可用的表述建议。

---

## 一、图3a：DAG 边出现频谱（Edge occurrence spectrum）

### 1.1 图中实际展示的内容

- **横轴**：共享同一条有向边 (from → to) 的物种数 (1 至 n_sp，本案例约 32)。
- **纵轴**：具有该「共享物种数」的边的条数。
- **分区定义**（据 `fig3_species_specific_causal_structure.R`）：
  - **Species-specific**：共享物种数 ≤ ceiling(n_sp × 0.25)，即仅被 ≤ 25% 物种共享的边；图中标注为 30 条、57%。
  - **Universal**：共享物种数 = n_sp，即出现在**所有**物种共识 DAG 中的边；图中标注为 5 条、9%。

### 1.2 可得出的客观结论

- 在 32 个物种上，CAST 共识别出 **53 条互不相同的因果边**（边以 from–to 对定义，跨物种去重）。
- **多数边为物种特异性**：57% 的边仅在不超过 25% 的物种中出现；**仅 9% 的边在所有物种中均出现**。
- 因此：**因果拓扑结构在物种间高度异质**，同一套环境变量在不同物种中形成不同的 DAG。

### 1.3 表述时需注意

- “物种特异性”在此处的**操作定义**是「≤ 25% 物种共享」，不是「仅 1 个物种」；若审稿人问起，可说明阈值。
- 边来自**各物种的共识 DAG**（bootstrap 后边强度/方向阈值），不表示“真实因果”的发现，宜在讨论中保留“条件依赖/因果结构”的表述。

## 二、图3b：物种特异性 ATE 系数热力图

### 2.1 图中实际展示的内容

- **行**：环境变量（按跨物种 ATE 方差降序，方差大的在上）。
- **列**：物种（按 ATE 轮廓 Ward 层次聚类排序，相似 ATE 模式的物种相邻）。
- **颜色**：ATE 估计值；红为正效应，蓝为负效应，白为接近 0。
- **星号 (*)**：该变量–物种组合的 ATE 在 **p < 0.05** 下显著（基于 DML 异方差稳健标准误）。

### 2.2 可得出的客观结论

- **同一变量在不同物种中 ATE 符号相反**：例如 Tmax Coldest Month、Elevation、Aridity Index 等，在部分物种中为显著正向（红）、在另一些物种中为显著负向（蓝），与副标题 “Same variable exerts opposite causal effects on different species” 一致。
- **效应强度在物种间差异大**：同一行内颜色深浅不一，说明同一环境因子的因果效应大小因物种而异。
- **变量×物种存在大量不显著或近零格子**：说明并非每个变量对每个物种都有显著因果效应，进一步支持**物种特异性**。

### 2.3 表述时需注意

- ATE 来自**中位数二值化处理 + DML**，解释为「该环境变量高于/低于中位数对物种出现概率的因果效应」；方向（正/负）有明确含义。
- 热力图排序（变量按 ATE 方差、物种按 Ward 聚类）是为了**突出异质性**，不改变“同一变量在不同物种中可正可负”的结论。
- 可简要说明：**传统变量重要性（如 RF 置换重要性）仅给出非负标量，无法区分正/负；ATE 热力图展示了 CAST 在“效应方向”上的额外信息。**

## 三、图3c：物种特异性因果角色分配

### 3.1 图中实际展示的内容

- **行**：环境变量；**列**：物种（与图3b 相同排序）。
- **颜色**：该变量在该物种共识 DAG 中的**因果角色**  
  - **Root**：无入边，仅有出边（上游驱动因子）。  
  - **Mediator**：既有入边又有出边（中介）。  
  - **Terminal**：无出边，仅有入边（下游响应）。  
- **灰色 (NA)**：该变量**未出现在该物种的共识 DAG 中**（即未被保留为节点）。

### 3.2 可得出的客观结论

- **同一变量在不同物种中可扮演不同角色**：例如 Tmax Coldest Month、Diurnal Range、Aridity Index 等，在部分物种为 Root，在另一些为 Mediator 或 Terminal，与副标题一致。
- **部分变量在多数物种的 DAG 中不存在**：灰色格子多，说明 CAST 的 DAG 学习与边筛选导致**并非所有变量在所有物种中都有因果节点**，与“物种特异性因果结构”一致。
- **角色分布有模式**：如 Diurnal Range、Aridity Index 在较多物种中为 Root；Elevation、Consecutive Wet Days 等更常为 Terminal；部分变量（如 Tmax Coldest Month）在物种间角色更多样。

### 3.3 表述时需注意

- 角色由 **DAG 的入度/出度** 定义，依赖当前共识 DAG 的边集；若 DAG 存在不确定性，角色划分也会有不确定性，讨论中可提及。
- “同一变量在不同物种中扮演根/中介/末端”是**描述性结论**，不涉及因果发现算法本身的正确性，可放心写入结果。

## 四、图3d：CAST 自适应筛选得分（跨物种热力图）

### 4.1 图中实际展示的内容

- **行**：环境变量；**列**：物种（与图3b、3c 相同排序）。
- **颜色**：**物种内归一化**的 CAST 综合筛选得分（`score_total` 在该物种内 min–max 归一化到 0–1 区间）。  
  - 深色 = 在该物种内得分**相对高**（更可能被保留）；浅色 = 相对低。

### 4.2 可得出的客观结论

- **不同物种的高分变量组合不同**：同一变量在不同物种中深浅不一；同一物种内，不同变量得分高低不同 → **筛选优先级因物种而异**，与“the pipeline adapts automatically”一致。
- **与图3b、3c 一致**：ATE 大、角色重要的变量往往在对应物种中筛选得分较高，但得分是 DAG + ATE + RF 的加权综合，故图3d 是**综合优先级**的直观展示。

### 4.3 表述时需注意

- **归一化是在物种内做的**：图3d 展示的是“每个物种内部变量的相对重要性”，**不能**直接比较同一变量在不同物种间的绝对得分高低。正文中宜写“不同物种对变量的筛选优先级不同”或“各物种内变量排序因物种而异”，避免“物种 A 的变量 X 比物种 B 的变量 X 更重要”这类跨物种绝对比较。
- 筛选得分公式（DAG 出度 + ATE + RF 重要性，自适应权重）在方法中已给出，结果部分只需概括“综合得分在物种间异质”即可。

## 五、四张子图之间的逻辑关系

| 子图 | 回答的问题 | 与 3.2 叙事的关系 |
|------|------------|-------------------|
| 3a   | 因果**边**是多数物种共有还是少数物种特有？ | 结构异质性（边层面） |
| 3b   | 同一变量的**因果效应方向与大小**是否因物种而异？ | 效应异质性（方向与强度） |
| 3c   | 同一变量在不同物种的 DAG 中**角色**是否不同？ | 结构异质性（节点角色层面） |
| 3d   | 不同物种的**变量筛选优先级**是否不同？ | 工具包产出（筛选结果）的异质性 |

顺序建议保持 **a → b → c → d**：先“有哪些边”（结构）→“效应如何”（ATE）→“角色如何”（根/中介/末端）→“筛选结果如何”（得分），逻辑连贯。

## 六、可写入稿件的结果表述建议（3.2 节）

以下为可直接或稍作修改后放入正文的表述，严格对应图3 四子图。

---

**第一段（总起 + 图3a）**

在 32 个物种上运行 CAST 后，因果结构在物种间表现出明显异质性（图3）。首先，在去重后得到的 53 条有向因果边中，多数边仅被少数物种共享：约 57% 的边仅在不超过 25% 的物种的共识 DAG 中出现，而出现在所有物种中的通用边仅占约 9%（图3a）。这表明同一组环境变量在不同物种中形成了不同的因果拓扑，而非单一共享结构。

**第二段（图3b）**

其次，同一环境变量在不同物种中的因果效应方向和强度差异很大。ATE 热力图显示，例如最冷月最高温、海拔、干旱指数等变量，在部分物种中具有显著正向效应（p < 0.05），在另一些物种中则为显著负向效应（图3b）。这类“同变量、反方向”的模式是仅基于相关或变量重要性的方法无法区分的，因为后者通常只给出非负的重要性标量。

**第三段（图3c）**

第三，变量在因果网络中的角色（根节点、中介节点、末端节点）同样因物种而异。同一变量在部分物种中为上游驱动因子（根），在另一些物种中为中介或末端响应；此外，不少变量在部分物种的共识 DAG 中不出现（图3c 灰色），进一步体现了因果结构的物种特异性。

**第四段（图3d）**

最后，CAST 的自适应筛选得分在物种间呈现不同模式：不同物种对同一组环境变量的相对优先级排序不同，说明流程能够根据各物种的 DAG 与 ATE 结果自动调整变量筛选（图3d）。综上，工具包在批量物种上的产出——因果边集合、效应方向与强度、因果角色以及筛选优先级——均因物种而异，为“物种间因果结构与效应的异质性”提供了系统证据。

## 七、审稿/讨论中可能被问及的问题与回应要点

1. **“物种特异性”的定义？**  
   图3a 中“物种特异性”边定义为被不超过 25% 物种共享的边；若采用更严（如仅 1 个物种）或更松的阈值，比例会变，但“多数边非通用”的结论仍成立。

2. **DAG/ATE 是否因果？**  
   结果中可统一采用“因果结构 / 因果效应（ATE）”的表述，讨论中说明 DAG 在因果充分性等假设下可解释为因果图，ATE 在 DML 假设下为因果效应估计；若存在未观测混杂，可表述为“条件依赖结构 / 处理效应”。

3. **图3d 能否比较物种间同一变量的绝对重要性？**  
   不能；图中为物种内归一化得分，仅支持“物种内相对优先级因物种而异”的结论，不做跨物种绝对比较。
